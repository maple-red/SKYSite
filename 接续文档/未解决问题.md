## 1. 服务器端访客统计显示 0/0 —— v1.0.1 已修复

- **现象**：本地正常，服务器上"总访客 0 / 当前在线 0"
- **已验证**：后端接口正常——`curl POST /api/visit` 后 totalVisitors 0→1，visitors 表能正常写入
- **根因（2026-08-03 定位）**：前端 `api/index.js` 的 `getSessionId()` 用 `crypto.randomUUID()` 生成会话 ID。该 API **仅在安全上下文（HTTPS / localhost）可用**。站点走 `http://服务器IP`（非安全上下文）时 `crypto.randomUUID` 为 undefined → 首次访问抛 TypeError → `recordVisit()` 未发出请求即失败 → 统计 0/0。
  - 本地用 localhost（安全上下文）所以正常；curl 不跑 JS 所以正常——与现象完全吻合。
  - **受影响范围**：访客统计、当前在线、说说列表、点赞、heartbeat 全走 `getSessionId()`，同样失效。
- **修复**：`getSessionId()` 增加降级方案（`crypto.randomUUID` 不可用时用 `时间戳+随机数` 生成），兼容 `http://IP` 非安全上下文。
- **待部署验证**：打包部署 test 包后，用 `http://IP` 访问首页确认总访客 ≥1。

## 2. https 无法跳转 http

- **现象**：外网访问 `https://服务器IP` 打不开、不跳转
- **已验证（服务器端全部正常）**：`curl -k -I https://localhost/api/stats` 返回 `301` 且 `Location` 指向 http，nginx 443 + 自签证书 + 跳转均正确
- **根因**：云控制台**安全组/防火墙未放行 TCP 443**——iptables 里 443 全程 0 包，请求根本没进到服务器
- **解决**：只能到云厂商控制台操作（无服务器命令）：
  - 云服务器（ECS/CVM）→ 实例 → **安全组** → 入方向 → 放行 TCP 443（0.0.0.0/0）
  - 轻量应用服务器 → 实例详情 → **防火墙** → 添加规则 TCP 443
- **状态**：等用户操作控制台后验证

## 4. 域名备案与部署（2026-08-03）

- **状态**：备案审核中（腾讯云已提交，预计 7~20 天）
- **现象**：`http://linyou.cloud` 访问显示「未备案」（备案拦截）；`https://linyou.cloud` 可正常访问（锁图标）

## 5. 服务器性能（2026-08-03 已解决）

- **现象**：docker compose 构建时 SSH 卡死
- **根因**：服务器仅 2G 内存无 swap，构建（Maven + npm + MySQL）爆内存 → sshd 无响应
- **解决**：重启 + 加 4G swap（成功）
- **建议**：以后小内存服务器部署前先加 swap
