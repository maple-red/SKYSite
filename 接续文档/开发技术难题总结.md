# 开发技术难题总结

> 用途：记录开发/部署中的技术难点与坑，便于少走弯路、备忘复用。
> 创建：2026-08-03

---

## 1. 小内存服务器跑 Docker 构建必加 swap（最高频）

- **现象**：`docker compose up -d --build` 时 SSH 卡死、服务器无响应
- **根因**：2G 内存无 swap，Maven + npm + MySQL 构建瞬间爆内存 → sshd 假死
- **解决**：加 4G swap（`/swapfile`）
- **教训**：≤4G 内存服务器部署前**先加 swap**，否则系统假死连不上

## 2. crypto.randomUUID 在非安全上下文不可用

- **现象**：服务器访客统计 0/0，本地正常
- **根因**：`crypto.randomUUID()` 仅 HTTPS/localhost（安全上下文）可用，`http://IP` 下为 undefined → 抛错
- **解决**：`getSessionId()` 加降级方案（时间戳+随机数）
- **教训**：涉及浏览器 API 时考虑非安全上下文（http://IP）场景

## 3. 国内服务器 Docker 镜像拉取慢/卡死

- **现象**：拉镜像卡死、构建卡在 npm/apk
- **解决**：配置云厂商镜像加速器（`/etc/docker/daemon.json`）；npm 用 npmmirror 源
- **教训**：国内服务器必配镜像加速，否则构建超时

## 4. HTTPS 打不开 ≠ 服务器问题，可能是安全组没放行

- **现象**：`https://IP` 打不开、不跳转
- **排查**：`curl -k -I https://localhost/api/stats` 返回 301 正常 → 问题在云控制台
- **根因**：安全组/防火墙未放行 TCP 443
- **解决**：云控制台放行 443（服务器命令无法完成）
- **教训**：先分清「服务器内正常」还是「外网进不来」，再决定查哪

## 5. 自签证书 HTTPS 会 301 跳回 HTTP

- **现象**：访问 https 自动跳 http
- **原因**：项目内置自签证书，配置了 https→http 跳转
- **注意**：证书自签浏览器不信任，首次访问弹警告（点"继续前往"）；备案通过后 http 正常

## 6. 前端打包别拖 node_modules

- **现象**：直接拖整个文件夹上传服务器几百 MB
- **解决**：`tar -czf` 打包时 exclude node_modules/dist/target/.git 等，生成 1~2MB 小包
- **教训**：部署传输用排除大目录的压缩包

## 7. Docker FORWARD 策略 DROP 是正常的

- **现象**：`iptables FORWARD` 是 DROP，担心防火墙坏了
- **真相**：Docker 默认行为，Docker 链已显式放行 80/443，不用管
