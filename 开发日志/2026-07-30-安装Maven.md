# 安装 Maven

**日期**: 2026-07-30
**类型**: 环境配置

## 背景
本地 Maven 目录 `D:\software\apache-maven-3.9.11` 被删除，但 Windows PATH 还残留了旧路径，导致 `mvn` 命令找不到。需要重新安装。

## 操作

### 下载
- 从 `dlcdn.apache.org` 下载 `apache-maven-3.9.16-bin.zip`（8.95MB）
- 网络需使用 `curl -4 -kL` 绕过 IPv6/代理问题

### 安装
- 解压到 `D:\software\apache-maven-3.9.11\`
- 目录名保持 `3.9.11` 以匹配旧 PATH 配置

### 验证
```
Apache Maven 3.9.16
Java version: 17.0.18
OS: Windows 11
```

## 结果
`mvn` 命令恢复可用，后端可以正常构建运行。
