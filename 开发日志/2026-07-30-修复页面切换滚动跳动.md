# 前端 Bug 修复 — 页面切换滚动位置跳动

> 提问时间：2026-07-30
> 技术栈：Vue 3 + Vue Router 4 + Vite + `<script setup>`
> 仓库：`maple-red/SKYSite`

---

## 一、问题描述

首页（/home）有 `position: sticky` 的 Hero 区域。下滑过 80px 时触发折叠：

```javascript
window.scrollTo({ top: boundary, behavior: 'smooth' })
// boundary = vh - 180 ≈ 720px
```

此时点击导航切换到其他页面（如 /about），新页面**先闪现 720px 位置，再跳回顶部**。

刷新目标页面后滚动正常 → 说明是 SPA 导航状态残留。

---

## 二、尝试过的 7 种方案（均失败）

| # | 方案 | 结果 |
|---|---|---|
| 1 | 删除全局 CSS `html { scroll-behavior: smooth }` | 失败 |
| 2 | 路由 `scrollBehavior` 返回 `{ top: 0 }` | 失败 |
| 3 | `<transition @after-leave>` 中 `scrollTo(0, 0)` | 失败 |
| 4 | `<transition @after-enter>` 中 `scrollTo(0, 0)` | 失败 |
| 5 | `onBeforeRouteLeave` 中提前 `scrollTo(0, 0)` | 失败 |
| 6 | `history.scrollRestoration = 'manual'` | 失败 |
| 7 | 将 `behavior: 'smooth'` 改为 `behavior: 'instant'` | 失败 |

---

## 三、根因分析

三个因素叠加导致：

### 因素 1：合成器线程 vs JS 主线程

`behavior: 'smooth'` 的动画跑在**浏览器合成器线程**上：

```
主线程: scrollTo(0,0) → 位置归零（成功）
合成器: 平滑动画还在跑 → 覆盖为 720px（失败）
```

即使 `onBeforeRouteLeave` 调了 `scrollTo(0,0)`，合成器的 smooth 动画会覆盖它。

### 因素 2：`position: sticky` 干扰

Hero 的 `position: sticky` 在组件卸载时被移除，Chrome 的 sticky 定位清理逻辑触发错误的滚动位置恢复。

### 因素 3：`scrollBehavior` 时序问题

`scrollBehavior` 在新页面组件挂载后触发。如果用户在此期间已经手动滚动，就会被强行拉回顶部。

---

## 四、最终修复方案

### 核心策略：只归零一次，旧页面消失前

```
过渡前 (@before-leave):
  ├─ scrollTo(0,0) — 旧页面还在，用户看不到变化
  └─ 新页面渲染时 scrollY=0

删除 @after-enter 的 scrollTo(0,0)
  └─ 防止抢跑用户的主动滚动

删除 scrollBehavior 的 {top: 0}
  └─ 只保留 savedPosition 处理回退
```

### HomeView sticky 特殊处理

```javascript
onBeforeRouteLeave((to, from, next) => {
  if (snapTimer) clearTimeout(snapTimer)
  isSnapping = false

  // 解掉 sticky → 防止 Chrome 组件卸载时滚动异常
  const hero = document.querySelector('.hero')
  if (hero) {
    hero.style.position = 'relative'
    hero.style.top = ''
  }

  window.scrollTo({ top: 0, behavior: 'instant' })
  void window.scrollY
  next()
})
```

### 过渡动画 GPU 加速

```css
.slide-fade-enter-active {
  transition: opacity 0.4s cubic-bezier(0.16, 1, 0.3, 1),
              transform 0.5s cubic-bezier(0.16, 1, 0.3, 1);
  will-change: transform, opacity;
}
.slide-fade-leave-active {
  transition: opacity 0.25s cubic-bezier(0.55, 0.085, 0.68, 0.53),
              transform 0.25s cubic-bezier(0.55, 0.085, 0.68, 0.53);
  will-change: transform, opacity;
}
```

## 五、修改的文件

| 文件 | 修改内容 |
|---|---|
| `frontend/src/App.vue` | `@after-leave` → `@before-leave`；删除 `onAfterEnter` |
| `frontend/src/router/index.js` | 删除 `beforeEach` 异步等待；`scrollBehavior` 只保留 `savedPosition` |
| `frontend/src/views/HomeView.vue` | `onBeforeRouteLeave` 添加 sticky 解绑 + 清除 snap 动画 |
| `frontend/src/style.css` | 过渡动画 GPU 加速 + 全局 `scroll-behavior: smooth` |

---

## 六、经验总结

1. **`behavior: 'smooth'` 不可取消** — 跑在合成器线程，JS 无法强制停止。路由切换前必须用 `behavior: 'instant'` 覆盖
2. **`position: sticky` 在 SPA 中有坑** — 组件卸载时 Chrome 的 sticky 回收逻辑可能干扰滚动位置
3. **`@before-leave` 优于 `@after-enter`** — 在旧页面消失前归零，用户无感知
4. **不要在新页面进入后调 `scrollTo`** — 会和用户的主动滚动抢跑
5. **`overflow: hidden` 锁滚动需谨慎** — 滚动条消失会导致内容左右晃动，需补偿 `paddingRight`
