## 四、问题修复记录

### 1. 背景图不显示（生产构建经典坑）
- **症状**：本地 dev 正常，部署后所有非首页背景图、头像全裂
- **根因**：图片用绝对路径 `/src/assets/bg-about.jpg`，Vite 打包**不会**把这种引用拷进产物 → 生产 404
- **修复**：改为 `import` 引入（App.vue 4 张背景图 + HomeView/AboutView/SplashView 头像，共 4 文件 9 处），本地构建验证 6 张图均进 `dist/assets/`
- **教训**：Vite 里图片必须 `import` 或用 `url('@/assets/...')`，绝不能用 `/src/...` 绝对路径

### 2. https 必须手输 http
- **根因**：无 SSL 证书，浏览器默认先试 https 失败。**https→http 跳转必须先有证书**（TLS 握手都过不了，跳转指令发不出去）
- **决策**：无域名，选自签证书方案
- **实现**：frontend Dockerfile 用 openssl 生成自签证书 → nginx 加 443 server 块 301 跳回 http → compose 暴露 443
- **效果**：`https://IP` → 浏览器警告 → 点"高级→继续前往" → 自动跳 http

### 3. 发布说说 415（真 Bug）
- **症状**：`POST /api/moments` 返回 HTTP 415，留言板/访客/点赞正常
- **根因**：`frontend/src/api/index.js` 的 `request()` 里 `...options` 在 `headers` 之后展开，**覆盖掉拼好的 headers**，导致带自定义 header（x-session-id）的请求丢失 `Content-Type`
- **修复**：headers 改为最后显式合并 `{ 'Content-Type': 'application/json', ...(options.headers || {}) }`
- **验证**：浏览器实测发布说说 201 成功入库

### 4. 访客统计"不涨"（非 Bug）
- 后端实测：不同 session 发请求计数 `1→2→3` 正常递增
- **是唯一访客设计**：同浏览器 session（localStorage）只算一次，刷新不涨；换浏览器/无痕/手机才 +1
- `recordVisit` 只在首页 `/home` 挂载时调用；`getStats` 在关于页读取

## 六、防火墙说明

### FORWARD 策略 DROP（正常现象）
- 不是被谁关了，是 **Docker 守护进程自动创建的链**（DOCKER/DOCKER-FORWARD/DOCKER-USER）并默认把 FORWARD 设为 DROP
- Docker 用自己的链显式放行容器流量（`DOCKER` 链里可见 80/443 ACCEPT → 172.18.0.4），转发正常
- **不用管，网站不受影响**

### iptables 入站规则（已写入部署说明 §8）
只放行 22/80/443，其余拒绝：
```bash
sudo iptables -A INPUT -i lo -j ACCEPT
sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT
sudo iptables -A INPUT -j DROP
sudo apt install -y iptables-persistent && sudo netfilter-persistent save
```
> 注意：③必须在④前；SSH 非 22 端口要改；云安全组是另一套独立规则，也要放行 80/443/22
