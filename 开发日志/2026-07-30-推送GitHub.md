# 项目推送 GitHub

**日期**: 2026-07-30
**类型**: 部署

## 背景
将本地项目 MyWebsite 推送到 GitHub 并设为公开仓库。

## 操作

### 仓库
- 仓库名: `maple-red/SKYSite`
- 可见性: 公开
- URL: https://github.com/maple-red/SKYSite

### Git 操作
- 分支: `master` → 重命名为 `main`
- 提交: 50 个文件，6928 行代码
- `.gitignore` 排除了 `node_modules/`、`target/`、`.claude/`、`backend/data/`（旧 H2 数据）

### 推送
```bash
git remote add origin git@github.com:maple-red/SKYSite.git
git push -u origin main
```

## 结果
项目已公开在 GitHub 上，可通过 SSH 克隆。
