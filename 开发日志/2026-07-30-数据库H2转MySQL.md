# 数据库切换 H2 → MySQL 8.0

**日期**: 2026-07-30
**类型**: 架构变更

## 背景
原来使用 H2 文件数据库，不适用于生产环境，切换到本地 MySQL 8.0。

## 改动内容

### 1. Maven 依赖更新
- **文件**: `backend/pom.xml`
- 移除 `com.h2database:h2` 依赖
- 添加 `com.mysql:mysql-connector-j`（runtime scope）

### 2. 数据库配置
- **文件**: `backend/src/main/resources/application.properties`
- 连接 URL: `jdbc:mysql://localhost:3306/skyl1n_portal`
- 用户名: `root`，密码: `<占位:mysql密码>`
- Hibernate dialect: MySQLDialect（自动检测）
- DDL: `update`（表自动创建）

### 3. 数据库创建
- 数据库名: `skyl1n_portal`
- 字符集: `utf8mb4`
- 表由 JPA 自动创建：`visitors`、`messages`、`moments`、`moment_likes`

### 4. 踩坑记录
- 失败：`characterEncoding=utf8mb4` → JDK 不识别
- 解决：改为 `characterEncoding=UTF-8`

## 结果
后端启动成功，MySQL 连接正常，4 张表自动创建。
