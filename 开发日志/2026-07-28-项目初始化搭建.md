# 项目初始化搭建

**日期**: 2026-07-28 ~ 2026-07-29
**类型**: 项目创建

## 概述
创建个人网站 SKYL1N Portal，全栈项目，前端 Vue3 + 后端 Spring Boot。

## 技术栈

### 前端
- **框架**: Vue 3 + Vite 5
- **UI 库**: Element Plus（抽屉组件）
- **路由**: Vue Router 4（SPA）
- **构建**: Vite 5.4
- **样式**: 纯 CSS + CSS 变量主题

### 后端
- **框架**: Spring Boot 3.3.0 + JPA
- **数据库**: H2 文件数据库（后续改为 MySQL）
- **Java**: 17
- **构建**: Maven

## 页面结构

| 路由 | 页面 | 功能 |
|------|------|------|
| `/` | SplashView | 粒子动画启动页 + 打字机效果 |
| `/home` | HomeView | Hero 全屏/紧凑切换 + 随手拍轮播 + 精选项目 |
| `/about` | AboutView | 个人介绍 + 经历时间线 + 技能/熟练度卡片 |
| `/projects` | ProjectsView | 项目作品集 + 分类过滤 + 详情抽屉 |
| `/moments` | MomentsView | 说说发布/列表/点赞 |
| `/message` | MessageBoard | 留言板发布/列表 |
| `/resume` | ResumeView | 简历页 |

## 后端 API

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/visitor/record` | POST | 记录访客 |
| `/api/visitor/stats` | GET | 获取访客统计 |
| `/api/visitor/heartbeat` | POST | 心跳更新在线数 |
| `/api/messages` | GET/POST | 留言列表/发布 |
| `/api/messages/{id}` | DELETE | 删除留言 |
| `/api/moments` | GET/POST | 说说列表/发布 |
| `/api/moments/{id}` | DELETE | 删除说说 |
| `/api/moments/{id}/like` | POST | 点赞/取消点赞 |

## 特性
- 滚动揭示动画（`reveal` / `reveal-left` / `reveal-right` / `reveal-scale`）
- 页面切换过渡动画（`slide-fade`）
- 全局背景图随路由切换
- 访客统计 + 实时在线人数
