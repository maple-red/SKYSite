# 响应式布局修复

**日期**: 2026-07-30
**类型**: 功能优化

## 背景
缩小浏览器时页面变形，手机端导航栏溢出。

## 改动内容

### 1. Navbar — 新增汉堡菜单
- **文件**: `frontend/src/components/Navbar.vue`
- ≤768px 时桌面菜单隐藏，显示汉堡按钮
- 点击弹出右侧滑出菜单（毛玻璃 + 过渡动画）
- 汉堡按钮带 ✕ 动效

### 2. 全局样式 — 填充 media query
- **文件**: `frontend/src/style.css`
- `@media (max-width: 768px)` 原来为空，现在添加了：
  - `.page-inner` 缩小 padding
  - `.page-title` / `.page-subtitle` 字号适配
  - 卡片圆角适配

### 3. 首页多级响应式
- **文件**: `frontend/src/views/HomeView.vue`
- Hero 头像 130px → 100px(768px) → 80px(400px)
- 标题 3.4rem → 2.2rem → 1.7rem
- Gallery 轮播网格转为单列
- Footer Stats 间距缩小

### 4. ContactCard 移动端调整
- **文件**: `frontend/src/components/ContactCard.vue`
- 左下角定位缩小、整体尺寸 48px → 42px

### 5. About/Projects 页适配
- **文件**: `frontend/src/views/AboutView.vue`、`frontend/src/views/ProjectsView.vue`
- 标题字号缩小、间距紧凑、标签按钮适配

## 结果
- 在 ≤768px 和 ≤400px 两个断点下都正常显示
- 手机端导航不再溢出
